# SalesPulse - Real Time Sales Analytics Dashboard

### Introduction
This project visualizes sales data using Python. It helps business owners to track monthly performance easily with graphs instead of manual calculation.

### Problem Statement
Manual calculation is slow. Business owners cannot easily find which month is best or which product is selling more.

### Objectives
1. To analyze monthly sales Jan-Jun
2. To track profit growth
3. To compare Product A vs Product B
4. To find best performing month

### Technologies Used
- Python
- Pandas - For handling CSV
- Matplotlib - For graphs
- GitHub - For hosting project

### Dataset
6 months data from Jan to Jun. Contains Sales, Profit, Product_A, Product_B. Highest sales in May - 40000.

### Results
- Monthly sales trend graph shows growth from 25k to 40k.
- Profit bar chart shows May highest profit 11k.
- Product A sells more than Product B.

### Conclusion & Future Scope
Successfully created dashboard. Future we can add sales prediction and make it live website.

### How to Run
pip install pandas matplotlib
python dashboard.py
